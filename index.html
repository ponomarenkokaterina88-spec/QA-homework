Команди термінала та Git

  • cd [шлях] — перехід у вказану папку
  • git clone [url] — клонування репозиторію на комп'ютер
  • git status — перевірка стану репозиторію та змінених файлів
  • git checkout -b [назва_гілки] — створення та перехід у нову гілку
  • git add . — додавання всіх змін до індексу (підготовка до комміту)
  • git commit -m "коментар" — збереження змін із описом
  • git push origin [назва_гілки] — відправка змін у репозиторій на GitHub
